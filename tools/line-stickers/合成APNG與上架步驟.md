# 合成 APNG 與上架步驟（LINE 動態貼圖）

**銜接**：畫師／你依逐格表匯出「透明背景 PNG 連號」後，用這份把連號圖合成 APNG，再上架。
**適用**：本組 16 張動態貼圖。

---

## 一、匯出 PNG 的注意事項（合成前先檢查）

- **背景透明**（去背），不要留白底。
- **尺寸統一**：每張貼圖建議 **370×320 px 以內**（LINE 動態貼圖上限 320px 高、370px 寬），全 16 張同尺寸。
- **連號命名**：`01.png 02.png 03.png…`，順序＝播放順序。
- **每張幀數 ≤20**。

---

## 二、幀延遲怎麼設（關鍵！決定播放秒數）

LINE 規定每張貼圖總長只能是 **1、2、3 或 4 秒**。幀延遲＝每幀停留時間：

| 想要秒數 | 幀數 | 每幀延遲 |
|---|---|---|
| 2 秒 | 8 幀 | 250 ms |
| 2 秒 | 16 幀 | 125 ms |
| 3 秒 | 12 幀 | 250 ms |
| 4 秒 | 16 幀 | 250 ms |
| 4 秒 | 20 幀 | 200 ms |

> 公式：**每幀延遲(ms) = 秒數 × 1000 ÷ 幀數**。
> 想讓某一幀「停久一點」（例如比讚頂點），可單獨把那一幀延遲調長。

---

## 三、方法 A：APNG Assembler（免費軟體，推薦）

1. 下載 **APNG Assembler**（Windows／macOS 皆有，搜尋 "apngasm"）。
2. 把連號 PNG 全選拖進視窗，確認**順序正確**（01 在最上）。
3. **Delay（幀延遲）**：設定分子/分母，例如 250ms 就填 `Delay = 250 / 1000`（或 `1/4` 秒）。
4. **Loops（循環次數）**：填 `0` = 無限循環（LINE 會在 4 秒內自動循環 1~4 次，設 0 最保險）。
5. 按 **Make Animated PNG** → 輸出一個 `.png`（這就是 APNG）。
6. 用瀏覽器打開輸出的 `.png` 確認會動、透明正常。

---

## 四、方法 B：ezgif 線上工具（不想裝軟體）

1. 到 ezgif 的 **APNG Maker**（`ezgif.com/apng-maker`）。
2. 上傳連號 PNG → 設定 **Delay**（單位 1/100 秒，250ms 就填 `25`）。
3. 勾選保持透明 → **Make APNG** → 下載。

> 線上工具方便，但去背/壓縮品質不一定理想，量產建議用方法 A。

---

## 五、上架 LINE Creators Market（電腦網頁版）

1. 電腦瀏覽器登入 **LINE Creators Market**（`creator.line.me`）。
2. **New Submission → Stickers**，貼圖類型選 **Animation（動態貼圖）**。
3. 上傳資產：
   - **Main image（主圖）**：240×240 px APNG
   - **Sticker images**：16 張 APNG（各 ≤320×370、≤20 幀）
   - **Tab image（聊天室縮圖）**：96×74 px（靜態 PNG）
4. 填**貼圖標題、說明、分類、售價、語言**。
5. **送審**（Submit）→ 等 LINE 審核（通常數天）。

---

## 六、常見卡關

| 症狀 | 原因／解法 |
|---|---|
| 上傳被擋「超過幀數」 | 某張 >20 幀，減幀或降秒數 |
| 動畫太快／太慢 | 幀延遲設錯，回第二節重算 |
| 背景變白底 | PNG 沒去背，或合成時沒保持透明 |
| 循環會頓 | 最後一幀 ≠ 第一幀，補一張接回起始姿勢 |
| 審核被退（版權） | AI 生成素材商用授權要先確認（見製作企劃第六節） |
| 檔案過大 | 減色／降尺寸，或減幀 |

---

## 七、送審前最終檢查清單

- [ ] 16 張 APNG，各 ≤20 幀、透明背景、尺寸統一
- [ ] 每張秒數為 1／2／3／4 秒之一
- [ ] 主圖 240×240、Tab 圖 96×74 備妥
- [ ] 圖上**無富邦人壽／邦拓通訊處**字樣或標識、無商品名稱代號
- [ ] AI 生成工具商用授權已確認、生成紀錄已保留
- [ ] 標題、說明、售價已填

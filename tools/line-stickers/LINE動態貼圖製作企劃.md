# LINE 動態貼圖製作企劃（16 張動作版）

**用途**：給畫師／AI 繪圖用的動態貼圖製作表 + 上架規格備忘
**主角**：邦拓通訊處 Q 版人物（造型、配色、字體全 16 張須統一）
**產出目標**：16 張 APNG 動態貼圖，上架 LINE Creators Market

---

## 一、規格與限制（送審前逐條核對）

| 項目 | 規定 |
|---|---|
| 檔案格式 | **APNG（Animated PNG）**，不可用一般 GIF |
| 一組張數 | 8、16 或 24 張（本企劃採 **16 張**） |
| 每張動畫長度 | 1、2、3 或 4 秒 |
| 每張最高影格 | **20 幀**（例：4 秒最多 20 張連續圖串聯） |
| 循環播放 | 4 秒內自動循環 1~4 次 |
| 背景 | 透明背景 PNG |
| 上架管道 | **電腦網頁版 LINE Creators Market → 新增貼圖 → 選「動態貼圖」** |

> ⚠️ 手機 App《LINE 拍貼》僅支援靜態／特效貼圖，**無法上架動態貼圖**，一定要用電腦網頁版。

---

## 二、製作與上架流程

1. **繪製連續動作＋文字**：在 Procreate／Photoshop／Clip Studio／Canva 畫出角色的關鍵姿勢分鏡，文字擺到定位。
2. **匯出 PNG 畫格**：把每個動作拆成多張「背景透明」PNG（一個動作約 5~15 張）。
3. **合成 APNG**：用 APNG Assembler 或線上轉檔工具，把連號 PNG 合成一個 `.png` 動態檔。
4. **網頁上架**：登入 LINE Creators Market → 新增貼圖 → 選「動態貼圖」→ 上傳 APNG → 送審。

> 💡 手繪門檻高時：可用剪映／CapCut 做短影片或綠幕動畫，再轉存透明背景的連號 PNG。

---

## 三、省工原則（沿用《晚安》逐格拆解法）

不用每一幀都重畫。把一個動作拆成 **2~4 個關鍵姿勢**，中間補幾張過渡幀就會很順：

- **人物**：單獨圖層群組，複製後用變形工具微調（縮放／旋轉／位移），不用整隻重畫。
- **文字**：也做進動畫，例如「縮小 → 放大 → 彈跳兩次」，比「人物動、文字不動」更有 LINE 貼圖感。
- **建議節奏**：每張控制在 **2~4 秒、20 幀以內**；循環動作（跳舞、揮手）讓收尾姿勢＝起始姿勢，接回去才不會頓。

## 五、每張逐幀拆法（範例：#2「讚啦！！」）

以 2 秒、8 幀為例，示範關鍵姿勢＋補間：

| 幀 | 人物 | 文字「讚啦！！」 |
|---|---|---|
| 1 | 蹲低預備（膝微彎） | 30%（縮小） |
| 2 | 起跳、雙手往上 | 70% |
| 3 | 最高點、雙手比讚 | 120%（放大過頭） |
| 4 | 頂點停頓 | 100%（回正） |
| 5 | 下落、手收回 | 110%（彈一下） |
| 6 | 落地微蹲 | 95% |
| 7 | 站直 | 100% |
| 8 | 回到第 1 幀預備姿勢（循環點） | 100% |

其餘 15 張套同樣邏輯：先定 2~4 個關鍵姿勢，再決定要補幾張過渡幀（動作大就多補、動作小就少補），全組 16 張的幀數不必一致，但每張都要 ≤ 20 幀。

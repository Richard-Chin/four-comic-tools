# LINE 動態貼圖製作企劃（16 張動態版）

**用途**：把已完成的 16 張靜態貼圖轉成動態，上架 LINE Creators Market
**主角**：Q 版長捲髮女生（咖啡色捲髮、黑上衣），16 張造型統一
**素材來源**：AI 生成工具（商用授權須先確認，見第六節）
**現況**：✅ 16 張靜態圖已完成 → ⬜ 待加動態、合成 APNG、上架

---

## 一、規格與限制（送審前逐條核對）

| 項目 | 規定 |
|---|---|
| 檔案格式 | **APNG（Animated PNG）**，不可用一般 GIF |
| 一組張數 | 8、16 或 24 張（本組 **16 張**，剛好成一組） |
| 每張動畫長度 | 1、2、3 或 4 秒 |
| 每張最高影格 | **20 幀** |
| 循環播放 | 4 秒內自動循環 1~4 次 |
| 背景 | 透明背景 PNG |
| 上架管道 | **電腦網頁版 LINE Creators Market → 新增貼圖 → 選「動態貼圖」** |

> ⚠️ 手機 App《LINE 拍貼》僅支援靜態／特效貼圖，**無法上架動態貼圖**，一定要用電腦網頁版。

---

## 二、製作路線（靜態圖已完成，採「整張變形」最省工）

因為 16 張已是完整插畫，動態不用重畫，只要「整張輕微變形＋局部元素動＋文字彈跳」。

**推薦單一路線**：
1. **Photoshop（時間軸／影格動畫）** 或 **iPad Procreate（動畫協助）**：放入靜態圖 → 用變形工具做 2~4 個關鍵姿勢（縮放／旋轉／位移 2~5%）→ 補間。
2. **文字獨立圖層**：要讓文字彈跳／放大時，把文字圖層分開，否則整張一起變形文字會歪。
3. **匯出透明 PNG 連號**（每張 ≤20 幀）。
4. **合成 APNG**：APNG Assembler（免費）或線上 ezgif。
5. **上架**：電腦網頁版 LINE Creators Market →「動態貼圖」→ 上傳 APNG → 送審。

## 四、省工原則

- **人物**：整張或局部（手、頭）獨立圖層，用變形工具微調，不重畫。
- **循環動作**（呼吸、揮手、比讚）：讓最後一幀＝第 1 幀，接回去不頓。
- **文字**：獨立圖層做「縮小→放大→彈跳兩次」，比整張硬變形更有貼圖感。
- **幀數**：動作大就多補幾張過渡幀、動作小就少補；每張 ≤20 幀即可，全組不必一致。

## 六、授權與合規備註

- 各家 AI 生圖工具的**使用條款不同**：能否商用、版權歸屬（你 vs 平台）差異大，付費方案通常才給完整商用權——上架前先查清楚該工具條款。

- 保守做法：保留生成紀錄（工具、日期、方案），來源記在本資料夾。

**品牌與內容合規**：

- 內容為正向問候／祝賀用語，不使用悲情、恐嚇、貶低式語言。

**公開 repo**：

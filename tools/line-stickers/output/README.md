這批是由 16 宮格靜態總圖切分後，用程式加上「整張輕律動」動態、壓進 LINE 規格的成品。

## 檔案

| 檔案 | 用途 | 規格 |
|---|---|---|
| `01早安.png` ~ `16夠帥了嗎.png` | 16 張動態貼圖 | 各 ≤282KB、約 194×206、8 幀、2 秒循環、透明背景 |
| `main_240x240.png` | 主圖 | 240×240、動態、≤300KB |
| `tab_96x74.png` | 聊天室縮圖 | 96×74、靜態 |

> 副檔名雖為 `.png`，實為 **APNG（動態）**，可直接上傳 LINE Creators Market「動態貼圖」。

## 已知限制

- 為壓進 300KB，降為 64 色（主圖 48 色），細緻插畫會有輕微色階分層。
- 動態為「整張輕律動」，非分部位動作（眨眼、比讚、文字彈跳需在繪圖軟體手動）。
- 尺寸偏小（約 194px）。若要更好畫質，改用 AI 生成的原始單張大圖重做。

## 上架前務必確認

- AI 生成工具的**商用授權**是否允許（見上層 `LINE動態貼圖製作企劃.md` 第六節）。
- LINE 現行規格（張數／秒數／檔案大小上限）以官網公告為準。
- 圖上無「富邦人壽／邦拓通訊處」字樣或標識（本專案品牌露出紅線）。
